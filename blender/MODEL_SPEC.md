# SafeOps 润滑油设备间低模建模规范

## 1. 本轮目标

本轮只将当前三维彩色方块升级为可辨认的工业低模外壳，验证整体 GLB 场景与现有 R3F、`SimulationEngine` 的绑定。

这不是通用资产库、场景编辑器或真实电厂复刻。`layout.json` 是当前 Demo 的一次性 Blender 施工数据，不作为长期平台协议。

## 2. 布局来源

- 业务实体及交互半径来自 `src/simulation/scenario.ts`。
- 二维空间关系、设备占地和管道关系来自 `src/game-2d/PixiScene.tsx`。
- 三维房间尺寸和区域划分来自 `src/game-3d/GrayboxWorld.tsx`。
- 坐标换算必须与 `src/game-3d/worldCoordinates.ts` 保持一致：`worldX = (sourceX - 700) / 80`，`worldY = (sourceY - 450) / 80`。

不要重新设计设备相对位置，不要调整业务实体 ID。

## 3. 坐标和尺寸

- Blender 使用米制单位。
- Blender Z 轴向上，X 轴为房间横向，Y 轴为房间纵深。
- 房间有效尺寸为 18m × 11m，高度 3.2m。
- 地面顶面为 Z=0。
- 所有设备必须落地，禁止悬空。
- `layout.json` 中的 `position` 表示对象在地面的中心点；`modelSize` 顺序为 X、Y、Z。

## 4. 整体布局要求

- 左侧为监测与告警确认区。
- 中部为主泵、备用泵和过滤器设备区。
- 右侧为 A、B 支路隔离区和漏油危险区。
- 南侧入口附近为安全准备区和工器具柜。
- 中间巡检通道必须连续，人物不得被设备、基础或管道堵死。
- 主泵和备用泵形成清晰的并联供油关系。
- 过滤器位于备用/下游供油管线上。
- A、B 支路阀门位于系统下游，漏油区域靠近 B 支路。

## 5. 设备建模要求

### 通用要求

- 使用规则几何体、倒角和简单组合建模。
- 不建机械内部结构，不追求照片级精度。
- 设备轮廓必须可以被非专业用户辨认。
- 所有业务设备是独立 Object 或独立父级 Empty。
- 业务根节点名称必须与 `layout.json` 中 `id` 完全一致。
- 不得把所有设备合并成一个 Mesh。
- 每个根节点原点放在设备占地中心的地面位置。
- 应用缩放和旋转 Transform，保持法线正确。

### 主油泵和备用油泵

- 包含底座、电机、联轴器防护罩、蜗壳泵体、进出口法兰。
- 两台泵使用相同结构和尺寸。
- 电机轴线水平，泵体接口与管道走向匹配。
- 可旋转部件单独命名为 `<entity-id>__rotor`。

### 过滤器

- 使用立式圆筒壳体、顶部盖板、侧向进出口法兰和底座。
- 顶盖与壳体轮廓清楚，但不制作内部滤芯。

### 压力仪表

- 就地压力表包含表盘、短立管和连接法兰。
- 远传压力装置包含方形变送器壳体、接管和小型底座。
- 表盘不需要真实刻度贴图，可使用简化指针和刻度凸起。

### 支路阀门

- 包含阀体、两侧法兰、阀杆和橙色手轮。
- 手轮必须是独立对象，名称分别为 `healthy-valve__handwheel` 和 `branch-valve__handwheel`。
- 阀体接口必须与下游管道处于同一轴线。

### 控制终端和工器具柜

- 控制终端包含柜体、倾斜操作台和双屏幕外壳。
- 工器具柜使用双开门柜体，柜门是独立对象。
- 柜门名称为 `safety-cabinet__door-left` 和 `safety-cabinet__door-right`。

## 6. 管道要求

- 所有管道在同一个 Blender 场景中生成和连接。
- 使用 Curve 加 Bevel 或低边数圆柱生成，统一管径。
- 转角使用圆滑弯头，不能直接让两根管道互相穿插。
- 分支处使用可辨认的 T 形连接。
- 设备接口附近添加简化法兰。
- 管道不得悬空、断裂或穿过设备主体。
- 管道高度以 `layout.json` 的 `elevation` 为准；若与设备接口冲突，只允许小范围调整接口高度，不改变平面走向。

## 7. 材质要求

本轮不使用外部贴图，仅使用基础 PBR 材质：

- `MAT_GraphiteMetal`：设备主体，深灰色，中等金属度，高粗糙度。
- `MAT_DarkSteel`：管道、法兰、设备基础。
- `MAT_SafetyOrange`：手轮、防护罩、操作部件和少量安全提示。
- `MAT_ScreenDark`：控制终端屏幕。
- `MAT_HazardOil`：半透明深红褐色漏油区域。
- `MAT_Concrete`：地面和设备基础。
